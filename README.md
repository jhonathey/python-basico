# Python Básico — Katas y fundamentos de programación

## 📌 Descripción del proyecto

Este repositorio recopila las Katas y ejercicios prácticos desarrollados durante el módulo de **Python Básico**, como parte del Máster en Analítica de Datos.

El objetivo del proyecto es adquirir y consolidar los fundamentos de programación en Python mediante la resolución de diferentes retos prácticos, aplicando la lógica de programación, la manipulación de datos y la estructuración del código.

Las Katas permiten abordar diferentes problemas utilizando distintas soluciones, fomentando el razonamiento lógico, la capacidad de resolución de problemas y la búsqueda de código eficiente, legible y reutilizable.

## 🎯 Objetivos

- Comprender los fundamentos del lenguaje Python.
- Desarrollar la lógica de programación mediante ejercicios prácticos.
- Aprender a estructurar y reutilizar código mediante funciones.
- Manipular diferentes tipos de datos y estructuras de información.
- Aplicar buenas prácticas de programación.
- Introducir conceptos de Programación Orientada a Objetos (POO).
- Desarrollar autonomía en la resolución y depuración de problemas.

## 🧠 Conocimientos y competencias desarrolladas

A lo largo del módulo se trabajan y aplican los siguientes conceptos:

### 1. Tipos de datos básicos y funciones incorporadas (Built-in)

- Tipos de datos: `int`, `float`, `str`, `bool`.
- Conversión entre tipos de datos.
- Funciones incorporadas de Python.
- Entrada y salida de datos mediante `input()` y `print()`.
- Uso de funciones como `len()`, `type()`, `range()`, `sum()` y otras.

### 2. Estructuras de datos

- Listas (`list`).
- Tuplas (`tuple`).
- Diccionarios (`dict`).
- Conjuntos (`set`).
- Acceso, modificación y manipulación de estructuras de datos.
- Utilización de métodos propios de cada estructura.

### 3. Condicionales

- Uso de `if`, `elif` y `else`.
- Operadores de comparación.
- Operadores lógicos (`and`, `or`, `not`).
- Validación de datos y control de condiciones.
- Aplicación de lógica condicional en la resolución de problemas.

### 4. Estructuras de iteración

- Bucles `for` y `while`.
- Iteración sobre listas, cadenas y otras estructuras.
- Uso de `break` y `continue`.
- Recorrido, búsqueda y filtrado de elementos.
- Comprensión de iterables y uso de `filter()`.

### 5. Funciones en Python

- Definición y llamada de funciones.
- Parámetros y argumentos.
- Valores de retorno mediante `return`.
- Parámetros con anotaciones de tipo.
- Funciones anidadas.
- Funciones lambda.
- Alcance de variables.
- Modularización y reutilización del código.

### 6. Programación Orientada a Objetos (POO)

- Definición y creación de clases.
- Instanciación de objetos.
- Atributos y métodos.
- Constructor `__init__()`.
- Uso de `self`.
- Encapsulación básica.
- Validaciones y excepciones personalizadas.
- Interacción entre objetos.

### 7. Módulos

- Importación de módulos.
- Uso de `import` y `from`.
- Utilización de módulos de Python.
- Organización y separación del código en diferentes archivos.

### 8. Buenas prácticas

- Código legible y organizado.
- Uso de nombres descriptivos para variables, funciones y clases.
- Indentación correcta.
- Evitar duplicidad de código.
- Validación de datos.
- Manejo de errores y excepciones.
- Aplicación de soluciones claras y mantenibles.

## 🛠️ Tecnologías y herramientas

- **Python** — Lenguaje de programación.
- **Jupyter Notebook** — Desarrollo y ejecución de ejercicios.
- **Visual Studio Code** — Editor de código.
- **Git & GitHub** — Control de versiones y publicación del proyecto.

## 📂 Estructura del repositorio

El repositorio se organiza en diferentes ejercicios o Katas, agrupados según los conceptos trabajados durante el módulo.

Cada ejercicio tiene como propósito practicar una habilidad específica y aplicar los conocimientos adquiridos progresivamente.

## 📈 Metodología de aprendizaje

El desarrollo de las Katas se basa en un enfoque práctico e incremental:

1. Comprensión del enunciado y del problema.
2. Identificación de los datos de entrada y del resultado esperado.
3. Diseño de la lógica de resolución.
4. Implementación en Python.
5. Comprobación del resultado y validación de casos.
6. Identificación y corrección de errores.
7. Revisión de la solución y posibles alternativas.

## 💡 Conclusiones

Este módulo representa la base para el desarrollo de competencias técnicas orientadas al análisis de datos.

El aprendizaje de Python permite evolucionar desde la resolución de problemas básicos hacia la automatización de procesos, la manipulación de información y el desarrollo de herramientas que faciliten el análisis y la toma de decisiones basadas en datos.

Los conocimientos adquiridos en este módulo servirán como punto de partida para abordar contenidos más avanzados relacionados con análisis de datos, SQL, automatización, tratamiento de datasets y desarrollo de proyectos analíticos.
